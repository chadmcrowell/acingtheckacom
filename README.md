Landing page for the book **Acing the Certified Kubernetes Administrator Exam** by Chad M. Crowell and Rafael Brito, published by [Manning Publications](https://www.manning.com).

## About

A static site hosted on Netlify that promotes the CKA exam prep book. It includes:

- Book overview and purchase link (Manning Publications affiliate link)
- Author bios for Chad M. Crowell and Rafael Brito
- Social links (LinkedIn, YouTube)

## Development

The site is plain HTML/CSS — no build step required.

```text
index.html   # Main page
styles.css   # Styles
```

Open `index.html` in a browser or use any static file server to preview locally.
